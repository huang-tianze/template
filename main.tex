\section{trivival}
\subsection*{Gray Code 格雷码 反射二进制码 循环二进制码}
任意的相邻的两个格雷码只有一位不同。\\
计算方式：\verb|gray_code = m ^ (m >> 1)|

\noindent Tips:
\begin{enumerate}
    \item 如果将 $m$ 的格雷码 $g$ 再进行转换，则得到的一系列 $g$ 位于 $[2^p, 2^{p+1}-1]$ 内，即这是个循环。其中 $2^p \le m < 2^{p+1}$。
    \item 对于长度为 $2^n$ 的格雷码序列，有 $\sum_{i=2}^{2^n} a_{i-1} \oplus a_i$ 最小。
\end{enumerate}

\subsection*{Xor 异或}
\[
    \bigoplus_{i = 1}^{n} i =
    \begin{cases}
        n   & n \pmod 4 = 0 \\
        1   & n \pmod 4 = 1 \\
        n+1 & n \pmod 4 = 2 \\
        0   & n \pmod 4 = 3
    \end{cases}
\]

\subsection*{0-1 Matrix}
矩阵从 0 开始计数，即从偶数行（列）开始。\\
要求：
\begin{itemize}
    \item 每一行数字的和构成 $\{0,1,2,3,\dots,n-1\}$ 的数字集合。
    \item 每一列数字的和构成 $\{0,1,2,3,\dots,n-1\}$ 的数字集合。
    \item 数字连通块恰好有 $n$ 个。
\end{itemize}
结果：
\begin{enumerate}
    \item $a_{i,j} = \min(i,j) \ \& \ 1$
    \item 考虑偶数行从左向右排列 $n-i-1$ 个 1，奇数行全为 0；考虑奇数列从上到下为 $n-i$ 个 0，然后为 $i$ 个 1。将两个矩阵点或即可。
\end{enumerate}

\subsection*{gcd}
$\forall n, \gcd(x,y)=n$，同时 \verb|x^y| 最小，则 $x,y$ 的一个可能的取值：\verb|(n << __bit_width(n))|, \verb|(n << __bit_width(n) | n)|。

\subsection*{mex}
对于集合 $A = \{x: x \in [L,R]\}$，记操作 op：从集合中任意选取至少一个元素，计算这些元素的 bit\_and，并将新元素加入集合。则最终 $mex(A)$ 由以下函数输出：
\begin{minted}{cpp}
int solve(int L, int R) {
    int b1 = bit_width(L) ? bit_width(L) : -1;
    int b2 = bit_width(R) ? bit_width(R) : -1;
    if(b1 == -1) return R + 1;
    else if(b1 == b2) return 0;
    else if(b2 > (b1 + 1)) return R + 1;
    else {
        int ans = R - (1LL << b2) + 1;
        int l = 0; // L 能自己构造的下限
        for(int j = b1; j >= 0; j--) {
            if((L >> j & 1) == 0) break;
            else l |= (1LL << j);
        }
        if(l <= ans) ans = R + 1;
        return ans;
    }
}
\end{minted}
